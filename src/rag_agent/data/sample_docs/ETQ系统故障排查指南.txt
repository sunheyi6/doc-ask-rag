ETQ 系统常见故障排查指南
======================

本文档汇总 ETQ 系统在生产环境运行中的常见故障与排查方法。

一、ETQ 服务无法启动
-------------------
现象：执行 docker start etq-server 后容器反复重启。
排查步骤：
1. 查看容器日志：docker logs --tail 200 etq-server
2. 若日志出现 OOM 字样，说明 JVM 内存配置不足，调大 JVM_OPTS 中的 -Xmx 参数
3. 若提示 MySQL 连接超时，检查 MYSQL_HOST 指向的数据库实例是否可达
4. JDK 版本错误时日志会输出 UnsupportedClassVersionError，请确认镜像内 JDK 为 17+

二、问答功能返回异常
-------------------
现象：用户提问后 ETQ 返回"服务内部错误"。
排查步骤：
1. 检查 etq.llm.api-key 配置是否有效，可通过 curl 调用通义千问接口验证
2. 若模型为 qwen-turbo 且请求量大，可能触发限流，可切换 qwen-plus 或提升配额
3. 查看 ETQ 日志文件 /opt/etq/logs/etq.log 中的 Error 级别记录

三、文档上传失败
---------------
现象：上传 PDF 文件时提示"文件解析失败"。
排查步骤：
1. 确认文件未加密、未损坏，扫描件需要先经过 OCR 处理
2. 检查 etq.storage.path 磁盘剩余空间，df -h 确认
3. 单文件大小限制为 50MB，超出请拆分后上传

四、检索结果不准确
-----------------
现象：问答回答与文档内容不符。
排查步骤：
1. 确认文档已成功建立索引（ETQ 管理后台可查看索引状态）
2. 文档更新后需触发重新索引，ETQ 默认 24 小时自动重建一次

五、联系支持
----------
以上方法无法解决时，请收集 ETQ 版本号、日志片段和环境信息，提交工单至 support@etq.example.com。
